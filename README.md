# PHP Words

Aplicación web sencilla y ligera para consultar las palabras reservadas de PHP, filtrándolas por texto y categoría de forma dinámica y sin dependencias externas.

## Ejecución
Simplemente haz doble clic en el archivo `index.html` para abrirlo directamente en tu navegador web favorito.
